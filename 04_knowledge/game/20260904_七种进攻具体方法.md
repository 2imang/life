## 七种进攻具体方法

### 课程板书

**进攻 = 表明男女意图**

1. 表达自己有需求
2. 表达自己对于关系的想法
3. 表达自己对于关系进展的具体动作（预期）
4. 暧昧表情包、暧昧称呼
5. 描述暧昧画面（高阶）
6. 互动本身产生爱情的感觉（高阶）
7. 聊骚（高阶）

### 课程说明

- 本课只解决一个细节：进攻的具体动作、具体言语、具体方式；进攻的前提、进攻之后女生反馈该怎么处理，在别的课里讲。
- 许多学员不明确"可以怎么进攻、想进攻可以用哪些言语"，本课给出非常细节落地、可以直接说的话。
- 前四条是所有人必须掌握的，非常简单，讲完之后就可以直接用出来，已经足够支撑你跟女生的关系发展到恋爱、甚至发展到婚姻。
- 后三条（高阶）需要一定的社交领悟力、理解力、人生阅历，会用聊天记录让大家更好地感受；是非必选项——如果性格内向、直男、不想搞得太累，后面这三个不需要也 OK。
- 网上看到的进攻多是后三种，但其实你根本用不好，还不如不用；前四种无论什么性格，知道原理之后都能用出来。

### 进攻的定义与为什么必须进攻

- 进攻的意思 = 向女人传递一种**男女之间的意图**：让她感受到，你们之间不仅仅有平淡的、普通的朋友关系，而是可能会有更多可能性。
- 为什么必须进攻：人和人社交一定都有一个目的（和朋友社交是为了互相开心、建立可以互相提供价值的联系）；如果你毫无目的，就会倒向最差的结果——你们俩没有关系，而且女生的时间也很宝贵。
- 注意区分（很多人会理解错）：这种可能性**不是**马上睡觉、不是马上开房、不是马上恋爱。如果进攻尺度太大、太猛，女生就会拒绝你。
- 这里说的更多可能性：可能会有一些暧昧的聊天，可能是我们会见一面，这个就叫更多可能性了。

### 一、表达自己有需求

- 定义：让女生知道，你现阶段是有这种恋爱需求的。这是最简单的进攻、程度最轻的进攻，本质是暗示。
- 可以直接用的话术：
  - 我最近经常看到朋友秀恩爱，我也好想恋爱。
  - 我有时候看到恋综上面甜甜的画面，感觉也想恋爱了。
  - 有时候觉得一个人有点孤单。
- 原理：用很直白的言语，让对方知道你想要恋爱、想要有甜甜的爱情，这就是一个典型的进攻。
- 反馈：如果对方也对你有意思，她会来配合你——比如"我也想恋爱了""我也觉得我们俩聊得挺开心的"，或者跟你共同描述自己也有窗口、也有需求。
- 对方不接：你就知道，她目前对跟你进一步暂时没有兴趣。

### 二、表达自己对于关系的想法

- 定义：给"她"以及"你们之间这段关系"下一些定义。
- 话术示例：
  - 我觉得我们俩挺合拍的。（潜台词：我们可能是可以再往前走一步的关系）
  - 我觉得咱俩挺甜的（相处的时候）。（给她一个"你们之间会是爱情关系、或者会是暧昧关系"的想法和念头）
  - 假如咱俩恋爱了，咱俩要去 xxx。（也是一种对关系的想法）
- 本质：你说的话让她觉得，你不想只停留在朋友关系上。

### 三、表达自己对于关系进展的具体动作（预期）——最最好用的一点

- 定义：所有的"预期"都是在讲这一点——让她知道，你会对她做一个具体动作、你想跟她做一个具体动作。
- 为什么最好用：第一、二点跟女人说了之后，你并不知道要进展到哪一步、接下来该到哪一步；第三点可以让你跟女生非常直接地到达某一种结果、某一种效果。
- 话术示例（由轻到重）：
  - 咱俩以后可以多聊聊天。（要求以后多聊天，肯定是为了以后可能要发展恋爱关系而设定的）
  - 咱俩以后可以多见见面。（更进一步的动作）
  - 见面了我牵你的手，你会不会开心呀？（一个对牵手的具体动作）
  - 晚上咱俩可以打语音，我觉得咱俩聊天会很开心。
- 连环框架（升级关系的节点）：先表达让女生可以跟你多聊天 → 再表达让她跟你多见面 → 多见面表达完之后，就可以落实实际约会 → 约会之后再尝试聊：牵手这个动作 → 接吻这个动作 → 住一起这个动作。你会发现这几个动作，就把你跟女生从认识不断延伸到了在一起——这就是非常实际的升级关系节点。
  - 迷茫时对照：看你们在哪一步了——如果你们经常聊天了，就提见面这个点；如果已经实际约会了，就提牵手。
- 要的结果不一定就是"睡一起"：说白了，你是在向女人要一个非常具体、非常实质的结果，但这个结果不一定就是睡一起——只能聊天的情况下变成见面，就是一种进展；只能见面的情况下变成牵手，也是一种进展。
- 求稳做法：如果还想更稳一点，可以在每个环节里面穿插更多动作、多次重复地去做。例如：我们俩多聊天之外，还可以说多语音、多视频、每天早晚安、互相唱歌给对方听、讲故事给对方听、约定见面的时候互相送什么伴手礼、约定牵手的时候要告诉对方什么感觉、在什么样的环境下去牵手——你会发现几乎无所不包。
- 评价：这是整个升级关系里面，对普通人最最好用、最好理解、最好落地的（没有之一）：直接告诉她，你想跟她完成的一个关系的具体动作，动作根据你们俩相处的情况来定；这样做，你跟女生就会有实际的关系进展。

### 四、暧昧表情包、暧昧称呼

- 称呼升级（直接在称呼上面改）：叫她宝宝、猪头、可爱、亲、亲爱的都可以。
  - 示例：她说"怎么了，宝宝"；"宝宝，亲亲我抱抱"；"脸蛋红红的，说话也跟一个宝宝一样"。
- 暧昧表情包：爱心发射、亲亲的表情包、"要亲亲要抱抱"、比心等。
- 尺度与建议：到换称呼、发暧昧表情包的时候，已经是程度比较重了，要先确定对方对你的反馈比较好再用；新手把握不好尺度的情况下，优先用前面几种——比如表达一个具体的关系动作（"以后要多见见面"），风险会小很多。

### 五、描述暧昧画面（高阶）

- 为什么有效：女人非常有想象力、非常感性，描述画面会让对方急剧地脸红心跳、加速你们俩的关系进展。
- 为什么标高阶：这一块也是最容易出问题的地方，很多人做不好这件事；建议想进一步研究的兄弟、有一定阅历的兄弟来用。
- 话术示例：
  - "其实我最想做的是，我和自己爱的人一起手牵手、光着脚丫子一起漫步在沙滩上，讲讲心里话；累的时候坐在沙滩上，你靠在我怀里，我从后面抱着你，你把脸贴在我身上。"
  - "看着月亮、看着江景，一起吹着风、听着音乐；你靠着阳台，我从后面抱着你，把脸贴在你脸上。"
- 做法技巧：非常简单——从你的脑海里面去想一个非常浪漫的场景，然后把它描述出来就可以。
  - 当场示例（想聊接吻）：先确定要聊接吻 → 想什么场景下会接吻（比如在家里烛光晚餐）→ 可以说："如果两个人在家里一起做做饭、点两根蜡烛，我会感觉非常浪漫；吃完饭我们俩可能会互相对视，你可能会有害羞，这时候我就会亲你；你会看到我跟你非常近的脸庞，会感受到心跳在加速。"
- 描述维度（描述时站在对方角度）：
  - 视觉描述：她眼睛能看到的东西
  - 感受描述：她能感受到的东西
  - 听觉描述：她能听到的东西（比如她会听到我在耳边跟你说"我很喜欢你"）
  - 身体反应描述：如心跳加速
- 效果：女生是真的会想这种画面。效果上限很高（老师原话：以前只凭聊这些画面，就能把女生聊得"流水了"——活生生靠聊天把她聊得"想要了"）。女人非常喜欢看"小黄文"、想象力非常丰富；想建立短期关系的兄弟，这个技巧值得好好琢磨，它其实可以把女人对你的兴趣度和喜欢程度拉高。

### 六、通过互动本身产生爱情的感觉（高阶）

- 示例一（手机梗）：
  - 她："我不用苹果，哈哈哈哈华为。"
  - 你："只要你用华为，我就觉得你牛逼。你要是不用华为，反正是你就牛逼。"（潜台词：我才不管你用什么，反正我就觉得你牛逼——因为我很喜欢你）
  - 效果：一个"喜欢"的字都没说，但女生从你的言语里面感受到你很喜欢她；她说"我真是"并配一个无脸害羞的表情，你们继续自然互动（如"我要闹了哟"）——这就是通过互动本身产生的爱情感觉。
- 示例二（秒回）：
  - 你说"哎呀我要去忙了"（其实平常挺忙的）→ 她问"那你为什么还回我这么快呢？"→ 你答"因为是你呀，所以我都秒回。"
  - 没说过任何一句喜欢你，但女生通过你前面一直在秒回她、再加上这句"因为是你"，就会产生"这个男生可能很喜欢我"的感觉。这是最自然、最好的升级技巧。
- 示例三（喂饭 + "哎呀"拌嘴）：
  - 她问"那你还不吃饭吗？"→ 你"等你用嘴喂我。"→ 她"等着喂"→ 你"对啊"→ 她"好吧"（你发个问号）→ 她"你打算等多久？"→ 你"等你早就饿死了"→ 然后是一串"哎呀""你哎呀什么嘛""我不哎呀什么呀"的对话。
  - 要点：不需要通过言语具体去说你们的关系很暧昧，但你在言语的氛围里面已经很暧昧——就像女生含情脉脉地坐在你旁边，不需要说任何话，你就能感受到那种暧昧的氛围。这是最自然的。
- 升级分级：基础技巧是直白地描述关系升级；中级技巧是通过画面、表情；最高级的技巧是你根本不说喜欢她，但她从你身上感觉到你喜欢她。
- 为什么难 / 怎么练：
  - 没有一个统一的原理可以给，这需要看到你跟女生实际的交流，在交流的过程中根据她的话来发散。
  - 练成前提：真正沉浸在跟她的快乐聊天中。那一刻并不是想着"我要用哪个技巧"，而是真的享受跟她的聊天、真的很开心很甜蜜，想把这种开心和甜蜜延续下去、把它们表达出来——真情流露，就会形成非常自然的暧昧互动（心流状态）。
  - 比喻：像吃苹果——你必须要咬到过苹果、感受过那种氛围和感觉，才做得出来；如果没感受过，别人怎么描述口感你都体会不到。这些偏感觉，要多念一下、多尝试去用。

### 七、聊骚（高阶）

- 示例（发图）：
  - 发一张很黄的图（中心区域打码）→ 她"哎呀"（非常害羞）→ 你"羞吗？"→ 她"你说呀"→ 你"我这样你会受不了"→ 她"哈哈哈哈你在谈事情还跟我聊这些"（你那会儿一边跟学员聊天一边跟她聊）→ 你"不过还是算了"→ 她"怎么嘛，怎么算了？"（她会反过来想向你要这个东西）
  - 原理：很多女人其实也很享受性，她之所以在你面前不这样，是因为你没有激发她对于男人的这种需求。
  - 继续推进：你说"你都没有回应呀，也不会抱着我，也不会叫"→ 她"抱你抱你"（配一个轻轻的表情）→ 你描述这种黄色的场面 → 她"嘿嘿，好喜欢什么嘛"。
  - 结果：后来两人聊了一些蹦迪等话题，也是拿到了结果。
- 说明：聊骚的具体步骤在过往的公开课里有非常详细的讲解（如何通过聊这个完成最后一步），这里只是简要展示一下大概是什么样的情况。

### 实战案例（学员 / 老师聊天记录，用来感受与启发）

- 梦里的约会：学员说"你晚上进入美梦的时候可以见到我"→ 她"要看得见摸得着的那种"→ 学员"怎么摸，抚摸吗？"→（再描述一个画面）→ 她"我该怎么说"（非常害羞）→ 学员"你闭上眼睛体验一下就好了"→ 她"哈哈哈哈好的嘞"。
- "你不休息，我怎么睡"："你还没有睡觉呢""我等会睡，你先睡""你不休息，我怎么睡"——潜台词是"你不睡的话我会睡不好"，典型的通过互动制造爱情的感觉。
- 酒品："我酒品贼好，除非遇到你"→ 她"是吗哈哈，你好不好"→"我要把你一次性喝醉"→"把我扔床上？不是让你喝多吗"——没有直接表达关系的声明，但仍然制造出了爱情的感觉。
- 睡左边还是右边：你"你平常喜欢睡左边还是右边？"→ 她"右边"→ 你"那我睡左边"→ 她"哈哈那你不是要睡了"→ 你"那要你躺在我右边才能睡得好"→ 她"我不在你还不是每天睡得香香的"→ 你（表情）"在我没动手之前，我确定好好说话"→ 她"哈哈我怎么没好好说话"——通过描述"睡左边还是右边"这件有趣的事，植入了一个两个人以后会睡在一起的画面。

### 总结

- 前四种：直接表达对女生关系的诉求、表达对女生关系的具体动作，是听了一遍今天就能直接去做、直接去说的。
- 后三种：需要去尝试、去摸索，要感受过那种氛围和感觉才做得出来（吃苹果的比喻），考验你本身的功底、阅历和文字功底；做不好的情况下直接不做都可以——只靠前面四个已经足够去升级关系。
- 今天的课出现大量可以直接复制粘贴的语句，可以记在笔记本上，下次跟女生聊天的时候直接用。
- 新手优先做前四件事：可以直接落地、风险相对小。
- 尤其第三点（表达具体动作 / 预期）会定向锚定你跟女人的关系：如果你不知道关系该往哪里发展了，就想一想下一个具体动作是什么——牵手、接吻、住家里，还是一起做饭、一起旅游——你就会有一条非常清晰的进攻路线，以及非常清晰的"自己跟女生在哪个进度"。
