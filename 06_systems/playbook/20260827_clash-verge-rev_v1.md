## clash-verge-rev

### 安装

1. 打开[clash-verge-rev项目GitHub官网](https://github.com/Clash-Verge-rev/clash-verge-rev)
2. 根据README.md下载安装包（DEB包、64位）
3. 在安装包所在文件夹打开终端，输入
```
sudo apt install ./*Clash*.deb
```

### 节点选择

可参考[机场推荐](https://yongjichang.com/)

### 配置

1. 点击Profiles
2. 粘贴URL
3. 点击IMPORT
4. 点击Home
5. 打开System Proxy

### 卸载

打开命令行，输入
```
sudo apt remove --purge clash-verge
sudo apt autoremove --purge
```
即可删除客户端以及系统配置
