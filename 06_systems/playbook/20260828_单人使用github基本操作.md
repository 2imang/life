## 单人使用github基本操作

### 创建仓库

1. 点击：右上角+号-New repository
2. 在Owner下拉菜单选择自己的账户
3. 在Repository name处输入仓库名
4. 在Choose visibility根据需要选择权限Public或者Private
5. 点击Create repository

### 克隆仓库

1. 在VS Code中点击Ctrl+Shift+P，输入Git: Clone
2. 然后选择要克隆的仓库
3. 选择本地存放路径

### 提交并推送更改

1. 在VS Code中点击左侧Source Control
2. Changes右侧加号Stage All Changes
3. 点击蓝色下拉菜单，点击Commit & Push
4. 在弹出的新文件窗口中，将光标移到最顶部（第一行，即所有以#开头的注释行之上），输入提交说明
5. 点击commit

> #### 暂存（Stage）、提交（Commit）和推送（Push）的区别
>
> **Staging（暂存）**：把修改过的文件挑出来，放入“待提交区”。
>
> **Committing（提交）**：把暂存区的更改打包成一个版本快照，存入本地 Git 仓库。
>
> **Pushing（推送）**：把本地仓库的版本记录上传到 GitHub 远程仓库。
>
> *为什么分三步？* 暂存让你有机会挑选要提交的文件；提交是本地存档，可以随时反悔修改；推送则是同步到云端，起到备份和共享的作用。三步递进，从修改到确认再到同步。
