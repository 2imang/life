## anaconda虚拟环境配置基本指令

### 查看所有虚拟环境

```bash
conda env list
```

### 创建虚拟环境

```bash
conda create -n <env_name> python=<python_version>
```

### 激活虚拟环境

```bash
conda activate <env_name>
```

### 退出虚拟环境

```bash
conda deactivate
```

### 彻底删除虚拟环境

```bash
conda remove -n <env_name> --all
```
